ROAD GUNNER — RANGED ENEMIES, VEHICLE EXPLOSIONS AND METAL GEAR LOOT
2026-10-07, Unity 6000.6.4f1 / URP

The latest user request replaces enemy buggy ram attacks with ranged combat,
adds an explosion on buggy destruction and ejects collectable metal gears
from defeated human raiders. This update is installed in both named scenes:
RoadGunner_Prototype and Level01_Wasteland.

RANGED BUGGIES
AI chooses reachable, visible firing positions around the player, slows before
closing and brakes at about 7.5 m. A closer player triggers retreat below
5.5 m, with a gap-restoring hysteresis band. Navigation checks alternative
angles around scenery instead of intentionally chasing the chassis centre.
Enemy collision-damage callbacks and enemy ram tuning fields are removed.
Normal Rigidbody/WheelCollider collisions remain physical; the player's
own ram sensor remains available. Default gun cadence/damage is unchanged:
2 rounds/s and 5 damage per hit. Both weapons and the player ground circle
still use the same 10 m radius. Cover blocks shots. AI distance/braking/
retreat values are editable in Settings/Enemy buggy.asset.

VEHICLE DESTRUCTION
One death produces one reusable explosion at the buggy position: a bright
cartoon flash, raised orange fireballs, expanding ground ring, sand burst,
soot plume, hot sparks, tumbling rusty scraps and an original low explosion
sound. The blast is visual/audio feedback and does not add area damage.
Armor blackens, the existing smoking wreck cleans up after 2.5 s, and the
existing three-scrap reward remains. The three effect slots cap particles
and return after 2.4 s. Restart clears all particle systems and flash meshes.

METAL GEARS
Each raider death awards exactly one kill and ejects one bevelled 3D steel
gear with a real central hole and rust accents. The gear leaves the raider's
waist, tumbles through a 0.6 s arc, then hovers/rotates over the terrain.
Collection starts after landing, so an immediate nearby kill still shows
the flight. Drive within the existing 2.5 m pickup radius to add one scrap
resource. Raider hit direction controls launch direction with modest spread;
world geometry shortens the horizontal throw and the drivable terrain sets
the landing height. The loot has no collision body and cannot obstruct cars.
The existing 60-object pool has separate gear/scrap visual groups. Vehicle
loot keeps its scrap plates and value of three. Overflow merges values,
so resource accounting is preserved. Pause freezes flight; restart clears it.

AUTHORING
The Scrap pickup prefab contains both visual groups and a reusable generated
gear mesh. Both scenes bind all 60 visual pairs and three explosion slots.
The idempotent DeathLootBuilder installer updates the scenes/prefab; Build
Prototype and the other enemy/range installers include this feature too.
Opt-in Editor diagnostics remain detached from saved scenes/player builds.
No paid art, external asset download, extra package or bitmap generation is
required. Geometry, particles and explosion WAV are native project assets.

VERIFICATION AND EVIDENCE
See Ranged-Loot-2026-10-07 for exact Play Mode reports and actual Unity captures.
The regression set covers approach/braking, ranged damage, retreat, actual
collision without ram damage, navigation, shared range/LOS, one death reward,
explosion cleanup/reuse, gear flight/persistence/collection, near-player
visibility, pause, overflow and restart. It also verifies the existing
vehicle controls/physics and session accounting. These are Editor results;
physical phone performance/multitouch are not inferred.
