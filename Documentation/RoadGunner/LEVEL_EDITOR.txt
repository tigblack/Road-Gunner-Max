CREATE / OPEN / SAVE
LEVEL > Create New Level: choose a new .unity file. Copies the working prototype's
existing player, UI, enemies/pickup pools, camera, lights, ground and perimeter.
Interior props and legacy encounters are cleared only in the new scene. Existing
levels are not overwritten. The designer can now place all desired content.
Open an existing scene from the LEVEL list or Other scene field. Use Prepare
Current Gameplay Scene once to add authoring sections/markers to an old level.
It keeps existing gameplay content/encounters and isolates the shared terrain asset.
Save Level writes the .unity scene plus dirty Mesh/config assets and bakes navigation.
Save As requires a new path; terrain, baseline, navigation and existing overrides
are copied to the new scene's _Data folder so future edits do not affect the source.
Clear authored content asks for confirmation and supports Undo; terrain, gameplay
systems, player spawn and perimeter remain. No external standalone application.

ENEMIES
ENEMIES: choose a human or vehicle prefab, press PLACE SELECTED PREFAB, click ground
in Scene View repeatedly. Escape or Cancel exits; Alt / right mouse navigate.
The original prefabs are discovered automatically. Additional prefab accepts an
assigned prefab asset. Actual ground is picked from this level's MeshCollider.
Enemy objects appear in Human Enemies / Enemy Vehicles under Authored Content.
Use ordinary Unity Move/Rotate, Cmd-D, Delete and multi-selection. The editor
rewires changed arrays after hierarchy edits; Save also synchronizes them.
Select an authored enemy: DEFAULT VALUE shows the shared existing tuning read-only.
Create per-instance LEVEL OVERRIDE clones the native tuning asset into this level's
_Data/Enemy Overrides folder. Edit fields below it; the default value is shown
alongside each field. Use prefab DEFAULT VALUE restores the shared reference.
Human fields: health, move speed, detection, melee reach/damage/cooldown,
replenishment delay. Vehicle fields: health, detection, max speed/torque, preferred
range/retreat behavior, gun fire rate/damage/aim/warmup, drop value and respawn/wreck
delays. Human drop remains fixed 1, and weapon range stays shared as in the game.
No fictional drop chance, patrol or spawn-delay stats were added.
Place Human Encounter creates an existing EncounterSpawn prefab with editable
count/radius/child points. Place Vehicle Spawn adds a transform to the existing
SpawnDirector markers. These use spare pooled enemies with their shared defaults.
Individual placements are one-shot by default; SETTINGS can enable replenishment.
Selected enemies show detection/attack circles; Show all authored ranges is optional.

OBSTACLES
OBSTACLES: choose a prefab, rotation/scale, optional random yaw/scale range, normal
alignment and grid snapping; click PLACE SELECTED PREFAB then Scene View ground.
Blocking props require a solid collider. Default layer is reused by the original
vehicle physics, enemy avoidance, line-of-sight and baked navigation. Decoration
explicitly disables colliders on the instance. No new collision layers are added.
Appropriate objects are Static, with no prop Update loop. Prefab connections remain.
Delete/Duplicate affect selected authored objects only; Clear selected prefab type
asks for confirmation. Normal Unity selection/Undo remains available.
Extract palette from existing environment exports existing scene art to prefabs;
Additional prefab also supports custom environment assets.

TERRAIN
The game uses a 10,201-vertex / 20,000-triangle square mesh, not Unity Terrain.
The editor edits this grid and its existing MeshCollider without adding geometry.
TERRAIN > RAISE / LOWER / SMOOTH / FLATTEN, set brush radius in metres, strength,
and flatten target WORLD height. EDIT RELIEF IN SCENE VIEW; drag left mouse on
visible ground. A brush ring previews the footprint. One drag is one Undo group.
Raise/lower strength is metres per second; smooth blends neighbouring grid heights;
flatten approaches the selected height with radial falloff. Mesh normals/bounds
and collision update immediately. Escape / Cancel releases the brush.
Optional tools: Flatten All / Set Base Height, Smooth All, Reset to captured baseline.
No runtime sculpting manager, terrain noise system or dense tessellation is added.
Save / Play bakes the existing AI Navigation surface, Default-layer physics geometry,
with the existing 0.18m voxel convention into a private Navigation asset.

PLAYER / BOUNDS / SETTINGS
LEVEL > PLACE PLAYER SPAWN, click ground; placement yaw controls facing.
Select spawn and use Move / Rotate to adjust it. Ground placement adds the existing
vehicle starting clearance (0.70m). Cyan car box/arrow show position and direction.
SETTINGS exposes recovery marker references, notes, individual replenishment,
existing encounter/vehicle spawn arrays and gameplay bounds. Bounds can be changed
in the window or resized with Scene View handles. They are authoring/validation
guides, not a replacement for the existing physical perimeter colliders.

VALIDATE / TEST
VALIDATION > VALIDATE LEVEL reports errors/warnings/info for missing start/ground,
missing gameplay references, missing scripts/prefab assets, malformed enemy wiring,
out-of-bounds placements, missing navigation/path connectivity and solid colliders,
stale navigation and active-cap overflow. Editing remains available with warnings.
PLAY LEVEL saves, synchronizes and bakes, validates required references, then uses
normal Unity Play Mode. Stop test returns to edit mode. Play Level does not create
another runtime level flow.

LIMITATIONS / V2
Relief sculpting targets the project's square grid; arbitrary imported meshes are
not supported by Smooth. Terrain deformation does not automatically reposition
props/enemies/spawn markers: move them to ground again when sculpting underneath.
A radius smaller than the 1m vertex spacing cannot sculpt finer detail.
Bounds are validation guides; changing them does not move/rebuild perimeter walls.
ActiveCap and legacy spare-pool capacity still limit encounters/vehicle spawn markers.
Metal Gear chance/patrol behavior/per-enemy gun range remain governed by the original
architecture. Individual tuning assets persist after deleting an enemy or resetting
its override; this preserves Undo and allows reuse, but unused assets may be cleaned
manually. No mobile device build/profiling was performed during this editor task.
V2 candidates: brush stamp/road tools, optional ground resnap, palette search and
thumbnails/category assets, multi-object stat overrides, encounter budget checks,
automatic navigation revision tracking after ordinary Transform edits, and targeted
mobile profiling of designer-authored level density.
