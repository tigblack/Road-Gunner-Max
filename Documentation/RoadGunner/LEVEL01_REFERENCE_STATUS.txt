Editing the prepared scene
Select Enemy Groups > Encounter NN and edit enemyCount or its child spawn points.
Moving the encounter root moves the whole group; marker points define positions.
If a count exceeds the number of explicit markers, additional points use a
predictable local circle with fallbackRadius. Invalid/blocked/unreachable spawn
locations are skipped. Positions project to navigation within 3 m.
Tools > Road Gunner > Level 01 > Validate Prepared Encounter Markers runs opt-in
Play Mode checks. Stop Play Mode before saving changes or rebaking navigation.
Select Navigation's NavMeshSurface and bake again after moving terrain/obstacles.
